# Назначение
Учебный стенд предназначен для демонстраций и автоматически очищается по воскресеньям в 03:00 UTC.

# Поддержка стенда
Обращения по учебному стенду принимаются с понедельника по пятницу с 09:00 до 18:00 UTC. Гарантированное время решения не установлено.
