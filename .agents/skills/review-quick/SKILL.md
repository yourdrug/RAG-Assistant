# Быстрая ревизия (только CRITICAL/HIGH)

Проведи быструю ревизию.

**Scope:** уточни у пользователя; если нет — файлы, изменённые в рабочей директории:

```bash
git diff --name-only HEAD
```

**Алгоритм:**

1. Загрузи skill `review-orchestrator` (кратко — только формат находок).
2. Вызови всех релевантных reviewer-agents, но попроси каждого сообщать
   **только** находки уровня CRITICAL и HIGH (без MEDIUM/LOW/INFO).
   Цель: быстрая обратная связь во время разработки, а не полный аудит.
3. Выведи результат сразу в чат, **без** сохранения в файл.
