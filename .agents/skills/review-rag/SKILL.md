# Ревизия RAG + изоляция данных

Проведи ревизию RAG-ассистента: качество пайплайна (ingestion, retrieval,
prompt building, generation) и изоляцию данных между пользователями/тенантами.

**Scope:** уточни у пользователя; если нет — весь репозиторий.

**Алгоритм:**

1. Вызови custom agents **именно в этом порядке**:
   1. `rag-pipeline-reviewer` — сам пайплайн
   2. `multitenancy-security-auditor` — изоляция (опирается на находки первого
      о том, где строится контекст и извлекаются документы)
2. Не вызывай остальных субагентов.
3. Находки уровня CRITICAL из области безопасности вынеси в начало ответа
   отдельным блоком с конкретным сценарием эксплуатации.
4. Остальное — приоритизированный список в чат, без сохранения в файл,
   если явно не попросили.
