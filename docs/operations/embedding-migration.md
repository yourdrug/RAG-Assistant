# Миграция embedding-модели

Каждая физическая Qdrant-коллекция привязана к идентификатору
`provider:model:EMBEDDING_REVISION`. Привязка хранится в отдельной пустой коллекции
`<corpus>__embedding_identity`: имя её единственного named vector содержит SHA-256
идентификатора. Создание атомарно, существующая привязка не перезаписывается.
Новые точки содержат `metadata.embedding_model`.

TEI: `TEI_EMBED_MODEL` должен соответствовать запущенному `--model-id`.
DeepInfra: модель берётся из `DEEPINFRA_EMBED_MODEL`. При замене весов с тем же
названием увеличьте `EMBEDDING_REVISION`. Проверка выполняется до записи векторов
и dense-поиска, включая benchmark. Смена модели той же размерности отвергается.

Старая непустая коллекция без привязки также отвергается: происхождение её
векторов нельзя установить автоматически. Данные не удаляются.

1. Сохраните исходные документы и резервную копию текущей коллекции.
2. Создайте новую пустую физическую коллекцию с новым именем и нужной размерностью.
3. В отдельном процессе индексации задайте `COLLECTION_NAME` новой коллекции и
   новую модель/ревизию. Переиндексируйте весь корпус, включая приватные документы
   и их ACL-метаданные. `ingest run` индексирует лишь указанный каталог; остальные
   документы должны быть обработаны тем же pipeline/outbox.
4. Проверьте число чанков, ACL и качество retrieval на новой коллекции.
5. Приостановите запись и смену конфигурации, дождитесь текущих запросов и worker.
   Переключите Qdrant alias на новую физическую коллекцию атомарным запросом
   `POST /collections/aliases` с действиями `delete_alias` и `create_alias`.
   Если alias ещё не используется, задайте новое `COLLECTION_NAME` всем API/worker
   процессам. Перезапустите процессы с согласованной моделью и коллекцией.
6. Очистите в Redis ключи answer cache `rag:cache:v3:*` и его reverse index
   `rag:doc:*` перед возобновлением запросов (ограниченными пакетами SCAN/UNLINK). Старую коллекцию и её binding сохраните на период отката.

При использовании alias привязка всегда ищется по физическому имени коллекции.
Alias и модель должны переключаться при остановленных запросах: одна лишь смена
alias не меняет модель уже работающего embedding-клиента.
