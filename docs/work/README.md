# Локальные рабочие материалы

Здесь хранятся локальные планы, заметки и промежуточные результаты работы.
Они не являются источником истины о поведении системы и не отслеживаются Git;
исключение — этот README.

Перед очисткой каталога переносите устойчивые выводы в постоянные документы
соответствующего направления из [каталога документации](../README.md).
Сырые benchmark-выгрузки храните в `docs/quality/artifacts/` (от корня проекта),
а не среди планов. Очистку выполняйте только после проверки нужных локальных материалов.
